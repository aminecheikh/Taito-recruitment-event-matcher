# Idea Log

Add ideas below using the template. Score each against the rubric before the team commits to one.

## Rubric (1–5 each)

| Criterion | Question |
|-----------|----------|
| Signal vs noise | Does it make the right conversations more likely and the wrong ones less likely? |
| Genuine over synthetic | Does it surface real capability/need that an AI-polished CV or job ad would hide? |
| Pain points hit | How many of the 9 pain points in [challenge-brief.md](challenge-brief.md) does it address, and how deeply? |
| Fairness & inclusion | Does it avoid disadvantaging people by nationality, language, education or career path? |
| Privacy & compliance | Minimal personal data, human decides, explainable — see [constraints.md](constraints.md) |
| Company pull | Would it change a company's view that the city is not a worthwhile talent source? |
| Demo-ability | Can we show it working end to end with synthetic data by the deadline? |
| Adoptability | Could Espoo realistically run it at their next event? |
